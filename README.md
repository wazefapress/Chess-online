# ♟️ Professional Online Chess Game (لعبة الشطرنج اونلاين)

لعبة شطرنج تفاعلية واحترافية مصممة للعمل على الويب ومتوافقة مع الأجهزة الذكية، وتدعم اللعب الفردي ضد الكمبيوتر أو اللعب الجماعي (Online) عبر الغرف الخاصة باستخدام تقنية Socket.io.

---

## 🚀 المميزات الرئيسية (Features)
- **لعب جماعي أونلاين (Online Multiplayer):** نظام غرف خاص يتيح لك إنشاء غرفة ومشاركة الكود مع صديقك للعب معاً في الوقت الفعلي.
- **اللعب ضد الكمبيوتر (Vs Computer):** إمكانية التدرب ومواجهة الخصم الذكي محلياً.
- **تزامن حقيقي للحركات:** مزامنة كاملة للحركات وتحديث الرقعة والتحقق من القوانين عبر سيرفر Node.js.
- **تصميم عمودي متجاوب (Responsive UI):** واجهة مستخدم مصممة خصيصاً لتناسب الشاشات المختلفة والأجهزة الذكية بشكل عمودي مريح.
- **المؤثرات الصوتية والاحتفالات:** أصوات حية لتحريك القطع ونهاية اللعبة، مع تأثيرات بصرية (Confetti) عند الفوز.
- **مؤقتات الوقت (Timers):** مؤقت تنازلي لكل لاعب لزيادة حماس وواقعية اللعبة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Frontend (الواجهة الأمامية):**
  - HTML5 / CSS3 / JavaScript (ES6+)
  - [jQuery](https://jquery.com/)
  - [Chess.js](https://github.com/jhlywa/chess.js) (للتحقق من قواعد الشطرنج وصحة الحركات)
  - [Chessboard.js](https://chessboardjs.com/) (لعرض وتفاعل لوحة الشطرنج)
  - [Howler.js](https://howlerjs.com/) (لإدارة وتشغيل المؤثرات الصوتية)
  - [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) (مؤثرات الفوز)
  - Socket.io Client

- **Backend (السيرفر):**
  - Node.js
  - Express.js
  - Socket.io (لإدارة الاتصالات المباشرة والغرف)
